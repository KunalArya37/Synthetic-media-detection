# Published Dataset Setup

This project will use a documented subset of published data instead of the
locally simulated benchmark generated by `dataset_downloader.py`.

## Sources

1. **GenImage** — the main training, validation, and internal-test source.
   - Official repository: https://github.com/GenImage-Dataset/GenImage
   - Paper: Zhu et al., *GenImage: A Million-Scale Benchmark for Detecting
     AI-Generated Image*, 2023.
   - Authentic class: ImageNet photographs (`nature`).
   - Synthetic class: images from BigGAN, GLIDE, VQDM, Stable Diffusion v1.4,
     Stable Diffusion v1.5, ADM, Midjourney, and Wukong (`ai`).

2. **Synthbuster + RAISE** — a held-out external test source only.
   - Synthbuster record: https://zenodo.org/records/10066460
   - Real reference images: https://mmlab.science.unitn.it/RAISE/
   - Synthbuster is restricted to non-commercial use. Cite both Synthbuster
     and RAISE in the report.

## Planned subset

| Split | Source | Real | Synthetic | Purpose |
|---|---:|---:|---:|---|
| Train | GenImage | 10,000 | 10,000 | Model learns its parameters. |
| Validation | GenImage | 2,000 | 2,000 | Selects the best checkpoint during training. |
| Internal test | GenImage | 2,000 | 2,000 | Final performance on unseen GenImage samples. |
| External test | RAISE + Synthbuster | 1,000 | 1,000 | Tests generalization to a different source. |

The 30,000 selected images require roughly 6–10 GB after extraction. Keep at
least 15 GB free while preparing and training.

## Download and prepare

Download only the GenImage generator folders required for the balanced subset
from the authors' official distribution. Extract them so the directory looks
like this:

```text
GenImage/
├── ADM/train/ai/       ADM/train/nature/
├── ADM/val/ai/         ADM/val/nature/
├── BigGAN/...
├── Midjourney/...
└── ...
```

Download and extract Synthbuster and its `real_RAISE_1k.zip` reference set
using the official instructions. Then run:

```powershell
python prepare_published_data.py `
  --genimage-root "D:\RawData\GenImage" `
  --synthbuster-real "D:\RawData\Synthbuster\real_RAISE_1k" `
  --synthbuster-synthetic "D:\RawData\Synthbuster\synthbuster" `
  --output-dir dataset_published
```

The script never modifies `dataset/`. It creates `dataset_published/` with
the required folders, a provenance `manifest.csv`, and `dataset_card.json`.
Only after reviewing that manifest should the application be switched from the
old demo data to the published dataset.
